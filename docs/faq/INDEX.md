# Nautilus Quant Book — Index

Living cache for how you learn and earn with markets, anchored on `nautilus-zerodte`.
Written for **future you**: busy, curious, still early in the journey.

## How to use this book

1. Read chapters in order the first time (mindset → process → honesty).
2. When you clip something into `inbox/`, ask the Book Architect to distill it here — don't leave raw Reddit threads as your memory.
3. Prefer one idea you can test in this repo over ten ideas you only bookmark.
